# AI Expense Tracker — Frontend Implementation Guide

## Project Context

Existing project folder:

```text
D:\my projects\gihub projects\python\task-manager-with-expense\
```

Current project already contains:

```text
frontend/
backend/
```

The existing **React task manager frontend and Python task manager backend must not be changed or removed**.

The new expense tracker must be added as a separate module inside the existing React frontend.

The task manager can continue to be used without creating an account.

After a user creates an account and logs in, they can access:

```text
http://localhost:5173/expense-tracker/dashboard
```

This document covers **FRONTEND ONLY**.

# 5. Authentication Behaviour

## Existing requirement

The task manager can be used by anyone without an account.

The expense tracker requires authentication.

Therefore:

```text
Task Manager
    ↓
Public access

Expense Tracker
    ↓
Account required
    ↓
Login required
    ↓
/expense-tracker/dashboard
```

## ProtectedExpenseRoute

Create:

```text
src/expense-tracker/components/ProtectedExpenseRoute.jsx
```

Responsibilities:

- Check whether the user is authenticated.
- If authenticated, allow access.
- If not authenticated, redirect to the existing login page.
- Preserve the destination if possible.

Example logic:

```jsx
if (!isAuthenticated) {
  return <Navigate to="/login" replace />;
}

return children;
```

Use the project's existing authentication mechanism.

Do not create a second authentication system if one already exists.

# 18. ML Category Suggestion — Frontend Behaviour

The model is later built with:

```text
TfidfVectorizer
LogisticRegression
```

The frontend must support human-in-the-loop prediction.

When the user enters:

```text
Uber to office
```

frontend should request prediction.

Example backend response later:

```json
{
  "predicted_category": "Transport",
  "confidence": 0.91
}
```

Frontend displays:

```text
Suggested category: Transport
Confidence: 91%
```

The user must be able to:

```text
Accept suggestion
or
Select another category
```

Never force the predicted category.

This is an important professional requirement.
